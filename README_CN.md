# 向量场可视化 Vector Field Visualizer

简体中文 | [English](README.md)

一个零依赖的单页交互演示，复刻并扩展了短片《四种理解"场"的方式》：**散度 ∇·F、旋度 ∇×F、梯度 ∇f、环量 ∮F·dr**——每个量的正负都能直观看见。

**在线演示：** https://mathjk.github.io/vector-field-viz/

## 功能

- **动态向量场**：单位圆域内的箭头网格 + 沿场线运动的粒子拖尾动画，复刻原视频的画风。
- **自定义函数**：可输入向量场 `F = (P, Q)`，或标量场 `f`（自动渲染为梯度场 ∇f）。纯文本输入 + 屏幕键盘 + 实时公式预览。
- **表达式解析器**：支持隐式乘法（`2x`、`xy`、`x(y+1)`）、`^`/`**`、unicode 符号（`× ÷ − π √`），以及 30+ 初等函数：`sin cos tan asin acos atan atan2 sinh cosh tanh asinh acosh atanh sec csc cot exp ln log lg log10 log2 sqrt cbrt abs sign floor ceil round trunc min max pow mod hypot clamp step`。
- **量的分布图**：散度、旋度在整个圆域上的常驻热力图（绿为正、红为负），以及环量随半径变化的曲线 `C(r) = ∮_{|p|=r} F·dr`。点击热力图或主画布即可移动观测点。
- **3D 曲面**：可拖拽旋转。默认画势函数 φ（路径积分数值重构；非保守场的曲面会出现"裂口"），也可切换为散度场 / 旋度场 / 流速场的曲面。标量模式下直接画 `z = f(x,y)`，2D 图上附带等值线。
- **预设**：一键给出 ∇·F=0、∇×F=0、环量=0、∇f=0 的情形，外加教学示例——比如奇点涡旋 `F=(−y,x)/(x²+y²)`（旋度处处约为 0，环量却是 2π，格林公式在奇点处失效）。
- **数值面板**：观测点处的散度、旋度、流速，以及沿 R=1 圆周的环量数值积分，按正负着色。

## 使用方式

直接用浏览器打开 `index.html`，或者起一个本地服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

无需构建、无任何依赖。

## 输入语法

| 写法 | 含义 |
|---|---|
| `2x`、`x(y+1)`、`xy` | 可省略乘号 |
| `x^2`、`x**2` | 幂运算 |
| `pi` / `π`、`e` | 常数 |
| `sin(x)`、`exp(-x^2-y^2)` | 函数需带括号 |
| `√(x^2+y^2)` 或 `sqrt(...)` | 平方根 |
| `mod(x,0.5)`、`step(e,x)`、`clamp(x,a,b)` | 分段构造工具 |

## 值得一试的对照

| 输入 / 预设 | 观察点 |
|---|---|
| `F=(x,y)`（旋度=0） | 粒子向外流；环量曲线贴零；势函数是光滑的碗 |
| `F=(−y,x)`（散度=0） | 粒子绕圈；`C(r)=2πr²` 抛物线 |
| 奇点涡旋 | `C(r)=2π` 水平线——环量全集中在原点；势函数曲面呈螺旋裂口 |
| `f=x²−y²`（标量） | 马鞍面 + 双曲等值线 |
| `P=sin(3x)`, `Q=sin(3y)` | 波浪条纹状的散度/旋度热力图 |

## 文件结构

```
index.html   页面结构
style.css    布局与主题（响应式，输入面板常驻）
app.js       表达式解析器 + 全部渲染（原生 JS，无库）
```

## 开发说明

解析器是纯 JS、自包含的：在 Node 下 `require('app.js')` 会导出 `parseAST`、`compile`、`circulation` 等函数，可直接写单元测试：

```bash
node --check app.js   # 语法检查
```
